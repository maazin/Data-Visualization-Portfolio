# Data Visualizations

A collection of Tableau dashboards exploring public datasets — from music charts to city taxi fares — built to practice data storytelling, exploratory analysis, and dashboard design.

## Workbooks

| File | Topic |
|---|---|
| `Billboard_Spotify_Hits.twbx` | Trends across Billboard chart hits and their Spotify audio features |
| `CreatingVisualizations.twbx` | Chart-design practice workbook covering different visualization types |
| `Forbes_HighestPaidCelebrities.twbx` | Breakdown of Forbes' highest-paid celebrities by category and earnings |
| `Intel_DataCenterRecommendation.zip` | Data-driven recommendation analysis for Intel data center site/config selection |
| `NYC_Green_Taxi_Fares.twbx` | Fare, trip, and demand patterns for NYC green taxis |
| `SuperBowlAnalysis.twbx` | Historical Super Bowl trends (scores, ratings, and matchups) |
| `UFO_Sightings.twbx` | Geographic and temporal patterns in reported UFO sightings |
| `UNESCO.twbx` | Global distribution and trends in UNESCO World Heritage Sites |

## Opening the workbooks

Each `.twbx` is a packaged Tableau workbook (data + visuals bundled together). Open with [Tableau Desktop](https://www.tableau.com/products/desktop) or upload to [Tableau Public](https://public.tableau.com/) to view and interact with it in a browser.
